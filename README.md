# smartmontools Trac archive

Archive of the smartmontools Trac site (former site:
<https://www.smartmontools.org>), migrated to GitHub on 2026-10-08.
This repository is a read-only archive (no source code).

## Tickets

- Every Trac ticket is an issue here; attachments are under `ticket/<trac-id>/`.
- GitHub issue numbers differ from Trac IDs — each issue notes
  "Migrated from Trac ticket #N" and carries a hidden `trac:N` marker for
  searching by the old number.

## Wiki

- The Trac wiki was migrated to this repository's wiki:
  <https://github.com/smartmontools/trac-tickets-archive/wiki>
- It holds the 61 project pages (the stock Trac help and meta pages were
  omitted); the interactive `smartctl` report pages are rendered as plain
  code blocks.
- Old ticket references link to the corresponding issues here, and source
  references link to <https://github.com/smartmontools/smartmontools>.

For new bug reports, feature requests and drive database entries use the main
tracker: <https://github.com/smartmontools/smartmontools/issues>
